# Point Lookout — North Stradbroke Island

Browser-file mirror of https://claude-creative-xbmc.vercel.app/, requested by Jez.
Retrieved 2026-10-05 UTC (2026-10-04 America/New_York).

The original project title, source comments and procedural scene are preserved.
No original project author or project-wide licence was identified on the public site.
This mirror does not claim authorship or apply a new licence to the original code.
Three.js r186 and ES Module Shims 2.8.4 have their MIT notices in vendor/.

All runtime dependencies are hosted locally. Serve this directory over HTTP(S);
JavaScript modules do not work from file://. Requires WebGL 2. Click/tap the
loading ring or press Enter once loading finishes to start the scene and sound.

Local hosting changes: a small Demos/Original navigation overlay, a blank favicon,
and these provenance/licence files. The old-browser import-map shim is retained
but not loaded because its blob-script probes conflict with the host CSP. The
mirror requires native import maps (Safari 16.4+, Chrome 94+, Firefox 108+).
The original scene JavaScript and CSS are unchanged.
