# Voxel Engine — hosted copy

Original: https://www.spawn.co/@mattshumer/voxel-engine
Creator credit: @mattshumer / Spawn. Retrieved 2026-11-09 at the user’s request.

This is the standalone browser distribution (JavaScript, CSS and engine.wasm), not an iframe or a recreation. Original engine and controls are preserved. Only the page title, description, visible hosting version and credit/gallery links were added. No Spawn guest tickets or account credentials are retained.

Serve this directory over HTTPS (localhost works for development). Requires WebGL2 and WebAssembly, with module workers. The site's existing CSP permits the required self-hosted assets and WASM.

The optional upstream VR build.json is absent (404); its existing caller tolerates that. All gameplay assets are local. No upstream source license was supplied with this distribution; original authorship is retained, and no new license is asserted.
