# Weatherglass Rainforest Terrarium

A living rainforest under glass with moss, ferns, a waterfall, a pool of schooling neon tetras and a fire-bellied toad. Grab clouds to make rain, shake them for lightning, stir wind, pour fog, mist plants and wipe condensation. Tap the pool with Feed to feed the fish.

The bearded dragon now lives in the separate dry [Bearded Dragon Terrarium](../bearded-dragon-terrarium/). No dragon is loaded, rendered or simulated here.

- Public route: https://jez237.com/demos/terrarium/
- Source: scripts/terrarium/
- Build: npm ci && npm run build
- Tests: npm test
- Keys 1–7 select tools, H hides controls, and ?ui=0 is a clean presentation view.
