# Weatherglass

An interactive miniature landscape enclosed in a glass terrarium: cloud manipulation, rain and storms, wind, fog, condensation, changing seasons, daylight and procedural ambient sound.

## Hosting

The uploaded HTML includes its styles, Three.js library, shaders, procedural geometry and audio. No external assets, API keys or Claude session are required. The supplied JavaScript and styles are unchanged. Hosting changes are limited to the browser title and a local SVG favicon.

The gallery artwork is an actual screenshot of the demo, captured with its supported `?ui=0` presentation option.

- Demo: https://jez237.com/demos/weatherglass/
- Mirror: https://jz237.github.io/jez237-site/demos/weatherglass/
- Gallery: page 2 on both sites.

Requires WebGL 2. Mouse and touch controls are supported. Use the toolbar for Hand, Wind, Cloud, Fog and Wipe; the climate drawer exposes time and seasons on narrow screens. Audio uses Web Audio and starts only after a browser-accepted interaction. The sound button mutes/unmutes it.
