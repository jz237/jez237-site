OpenClaw Gmail

A private, personal-use integration for the operator's own Gmail accounts. This is not a public email service or an official Google product.

OpenClaw Gmail checks newly arrived Inbox messages and helps the operator investigate relevant GitHub build-failure notifications. It uses Google's official Gmail API through the open-source gog command-line client.

Privacy policy

Effective October 28, 2026.

Access and purpose

The integration requests Gmail read-only access and the identity information needed to verify the connected account. It uses message identifiers, arrival times, senders and subjects to identify new mail. It reads message bodies for relevant GitHub failure notices to diagnose still-current failures.

It does not send email, change message labels, mark messages read, delete messages, or request Calendar, Drive or Contacts access. Google authorization grants technical access to read mail; the configured workflow limits its use to new Inbox mail and relevant GitHub failure follow-up.

Processing and disclosure

Processing runs on the operator's OpenClaw host. Relevant message details may be processed by the operator's configured AI model providers to provide requested assistance. Important results are delivered to the operator's private chat; GitHub is consulted when investigating build failures.

Mailbox contents and OAuth credentials are not published on this website. Google user data is not sold, used for advertising, or used by this integration to develop, improve or train generalized AI or machine-learning models. Access is used only to provide the operator-requested functionality.

Storage and retention

OAuth refresh tokens are stored in an encrypted local keyring, with its unlock credential restricted to the operator's account. Checkpoints retain message identifiers and check times to avoid duplicate work. Relevant failure notices may be retained privately while an investigation is pending; the workflow removes their bodies from its queue when closed. Private chat, model-provider and host backup records may have separate retention settings.

Control and deletion

The operator can stop the automation, remove local authorizations and checkpoints, and revoke access at any time through Google Account connections. Questions or deletion requests can be directed to the operator using the support contact shown on Google's authorization screen.

Google API Limited Use

OpenClaw Gmail's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.
