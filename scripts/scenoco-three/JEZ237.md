Rebuild (node 22+):

```bash
cd scripts/scenoco-three
npm ci --legacy-peer-deps --ignore-scripts
npm run build                                   # the @scenoco-three/* packages; examples import their dist
node build-jez237.mjs "$PWD" "$(git rev-parse --show-toplevel)"   # both games -> games/2026-10-31/, plus LICENSE.txt
```

`build-jez237.mjs` sets `assetsInlineLimit: 0`: jez237.com's CSP blocks fetch() of `data:` URIs, and
Vite would otherwise inline small models and sounds that way (Tiny Bastion then hangs on loading).

`npm run dev` inside an example still gives the live SceNoCo editor for modding.
