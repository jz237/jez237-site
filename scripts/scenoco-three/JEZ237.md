Rebuild (node 22+):

```bash
cd scripts/scenoco-three
npm ci --legacy-peer-deps --ignore-scripts
npm run build            # the @scenoco-three/* packages; examples import their dist
# then build each example with base './' into the games folder, e.g. with vite's build():
#   build({ root: 'examples/breakout', base: './', build: { outDir: '<site>/games/2026-10-31/scenoco-breakout', emptyOutDir: true } })
#   build({ root: 'examples/td',       base: './', build: { outDir: '<site>/games/2026-10-31/tiny-bastion',     emptyOutDir: true } })
```

After a rebuild, copy `LICENSE` to `LICENSE.txt` in each public folder (emptyOutDir removes it).
`npm run dev` inside an example still gives the live SceNoCo editor for modding.
