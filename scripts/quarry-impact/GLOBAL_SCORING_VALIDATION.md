# Global Hall of Dents

Implemented locally, not published. Entry points: title-screen Global Scores and completed single-player race results. No demo, online, unfinished race or solo-run submissions. Optional public nickname, no account. A browser UUID identifies the best entry; clearing browser storage creates a new identity.

Weekly top 100, reset Monday UTC. Score = round(1000 × (field − rank)/(field − 1) + 10 × field + condition). Best result per browser, not accumulated points. All race configurations share this casual board; results are player-reported, not server-authoritative. No anti-cheat claim.

Separate Cloudflare Worker `quarry-impact-scores`, one SQLite Durable Object, bounded 100 score rows and 1000 active 10-second IP cooldowns. Only salted hashes of IPs stored; raw addresses never stored in app tables. Output excludes browser IDs. Payload limit 1024 bytes, strict nickname/numeric validation, origin allowlist, parameterized SQL, atomic score updates, deterministic ties. No game state or existing multiplayer service modifications.
