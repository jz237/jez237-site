How Lightning Builds a Path to Ground

A direct-canvas scientific infographic showing how charge separation, a stepped leader, competing upward streamers, attachment, and the return stroke build a cloud-to-ground lightning flash, plus how rapid channel heating produces thunder.

Research added after publication

  • In a common negative cloud-to-ground flash, a stepped leader descends and can meet an upward streamer. That connection allows the bright return stroke to travel back up the existing channel. [1]
