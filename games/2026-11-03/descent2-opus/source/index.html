Source for this build

The engine is DXX-Redux, a Descent II source port, compiled to WebAssembly with Emscripten. The browser changes are published here under the same license as the engine.

Files

  • redux-web.patch — every engine change, against DXX-Redux commit 9fd90f03. The browser glue lives in d2/arch/web/.
  • build.py — the build script (Emscripten 3.1.46, Ninja).
  • d2loader.js and index.html — the page: file import, browser storage, CD audio, boot.
  • COPYING-DXX.txt — Parallax / D1X license for the engine.
  • LICENSE-PhysFS.txt — zlib license for PhysFS 3.2.0.
  • d2synth.src.js and synth-build.mjs — the MIDI music player, bundled with spessasynth_lib 4.4.2 (Apache-2.0). Sound bank: GeneralUser GS by S. Christian Collins (license).

Rebuilding

  1. Clone https://github.com/dxx-redux/dxx-redux into src/redux, check out 9fd90f03 and apply the patch with git apply redux-web.patch.
  2. Clone https://github.com/icculus/physfs tag release-3.2.0 into src/physfs.
  3. Install the Emscripten SDK 3.1.46 and Ninja, set EMSDK to the SDK folder, then run python build.py. The output is web/d2x.js and web/d2x.wasm.
  4. For the MIDI player, run npm install spessasynth_lib@4.4.2 esbuild@0.24.2 next to d2synth.src.js, then node synth-build.mjs.

The game page downloads its game resources automatically and caches them in your browser. Optional folder imports also support other copies and custom missions.
