One-time setup: load your game files

This page runs the game engine, but the game data comes from your copy of Descent II. Your files are stored only inside this browser and are never uploaded anywhere.

  1. Click Choose folder.
  2. Open your Steam install, for example D:\SteamLibrary\steamapps\common\Descent 2.
  3. Select the descent2 folder inside it and confirm. The browser may say "upload"; it only reads the files on your PC.

…or drag the descent2 folder here. GOG copies and original CD files work too.
