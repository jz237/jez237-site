# jez237-site

Source for [jez237.com](https://jez237.com/): a personal site with a Philadelphia garden journal, AI news and
images, browser games, interactive 3D demos, a weather console and a stock dashboard.

It is a static site. Most sections are plain HTML, CSS and JavaScript served from this repository's root; a few
are built from source that also lives here, with the build output committed.

## Layout

| Path | What it is |
| --- | --- |
| `index.html` | Home Base, the landing page |
| `plants/`, `garden/`, `photos/` | Garden progress, planting calendar and photo archive |
| `ai-news/` | AI News feed: `fetch_ai_news.py` builds it from `feeds.json` |
| `experiments/` | AI Images, Fish Health Lab and smaller experiments |
| `games/` | GameMaster Arcade and its games, in dated folders |
| `demos/` | Website Demos collection; the index pages are generated by `scripts/build-demos.mjs` from `demos/catalog.json` |
| `stock-market/` | Stock Command Center (built); its source is `stock-market-src/` |
| `weather/`, `multimedia/`, `computer-chronicle/`, `ai-sounds/`, `how-ai-works/` | Other sections |
| `ops/`, `network/` | Operations and home network pages |
| `assets/` | Shared styles, fonts, icons, `nav.js` (top bar) and `side-menu.js` (side rail) |
| `functions/` | Cloudflare Pages Functions; `_middleware.js` adds analytics and blocks source paths |
| `workers/` | Separate Cloudflare Workers (game scores, multiplayer, aircraft relay) |
| `scripts/` | Build sources for demos and games, checks, and data refresh scripts |
| `_headers`, `_redirects` | Cloudflare Pages security headers, caching and redirects |

Large music and video files are not in Git; they are served from `https://media.jez237.com`. See
[MEDIA_STORAGE.md](MEDIA_STORAGE.md). The Hidden Reef store is a separate project; see
[HIDDEN_REEF.md](HIDDEN_REEF.md).

## Working on it

Preview locally with any static file server from the repository root, for example:

```bash
python -m http.server 8000
```

Pages Functions do not run under a plain file server, so analytics injection and the Philadelphia demo's
service routes only work on Cloudflare. `ops/` is protected there by Cloudflare Access.

Sections with a build step keep their own `package.json`:

```bash
cd stock-market-src
npm ci
npm run build        # writes ../stock-market
node ../scripts/validate_stock_market.mjs
```

After changing `demos/catalog.json` or the head of `demos/index.html`, run `node scripts/build-demos.mjs`.

## Themes

The site has a dark default and a light theme. The choice is stored in `localStorage` under `theme` and applied
as `data-theme="light"` on `<html>`. The toggle is added by `assets/nav.js` on most pages, by
`demos/assets/theme.js` on the Demos pages and by the React app in Stock Command Center.

## Publishing

Cloudflare Pages builds this repository from Git, so a push to `main` is published within about ten minutes.
[AGENTS.md](AGENTS.md) describes the deploy wrapper (`scripts/deploy_jez237_pages.mjs`) and the checks required
after Philadelphia demo changes. A GitHub Pages mirror is built by `.github/workflows/pages.yml`.

Cloudflare Pages rejects any file over 25 MiB; `.github/workflows/pages-file-size.yml` reports the offending
file.

## Automation

- `news-refresh.yml` refreshes the AI News feed daily and commits the result.
- `stock-market-refresh.yml` refreshes market data on weekdays; `stock-market-validate.yml` rebuilds the app on
  pull requests and fails if the committed build is stale.
- `protect-live-deploy.yml`, `anatomy-studio-verify.yml`, `how-ai-works-tests.yml` and others guard specific
  sections.
